# 🚴‍♂️ TrailMate – Cycling & Trekking Companion App

## 📌 Overview

TrailMate is a modern, user-friendly application designed for cycling and trekking enthusiasts. It helps users discover trails, plan routes, track activities, and explore outdoor adventures with ease. The app focuses on delivering a seamless experience for both beginners and experienced adventurers.

---

## ✨ Features

### 🗺️ Trail Discovery

* Explore nearby cycling and trekking trails
* Filter trails based on difficulty, distance, and terrain
* View detailed trail information including elevation and route map

### 📍 Route Planning

* Plan custom routes for cycling or trekking
* Real-time route visualization
* Distance and time estimation

### 📊 Activity Tracking

* Track speed, distance, and duration
* Monitor performance metrics
* Save activity history

### 🌐 Interactive UI

* Smooth and responsive interface
* Clean and modern design

### 👤 User Profile

* Personalized dashboard
* Track achievements and progress
* Save favorite trails

## 🚀 Installation & Setup

### 1️⃣ Clone the Repository

```
git clone https://github.com/your-username/trailmate.git
cd trailmate
```

### 2️⃣ Setup Backend

```
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### 3️⃣ Setup Frontend

```
cd frontend
npm install
npm start
```
